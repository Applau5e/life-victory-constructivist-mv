> 给施工模型：这份文档是**唯一事实来源**。镜头编号、素材 ID、色值、帧号都在文中统一定义，配套的生图/抠图提示词在 `02_生图与抠图提示词.md`，素材 ID 两份文档一致。
> 合成：Remotion（2D、字体动画、照片蒙太奇、节拍同步、总合成）
> 3D：Blender（通过 Blender MCP 建模、动画、渲染成透明 PNG 序列）

## 0. 施工总原则（先读这一节）

1. **越庄严越好笑。** 画面一律按 1920 年代苏联构成主义国家宣传片来拍：严肃、宏大、机械、整齐。画面里不放一个"搞笑"表情包式的元素，笑点全部来自"史诗语言 × 如厕小事"的错位。
2. **体面铁律（不可违反）：**
   - 全片**不出现任何排泄物的具象形象**。"它"始终是一个抽象几何体：**红楔（The Red Wedge）**，致敬利西茨基《用红楔攻打白军》（1919）。
   - 主角**始终穿戴整齐**，"坐马桶"一律处理为端坐在抽象几何"王座"上，不出现脱裤、裸露。
   - "那漂着的，是我今天的尊严"中漂着的东西 = 红楔化作的**红星勋章**。
   - 所有马桶都是干净的白瓷，作为"纪念碑"来拍。
3. **所有文字都在 Remotion 里排版。** AI 生图只出无字画面（AI 生成中文字不可靠）。
4. **几何母题贯穿转场。** 每一个镜头的出画都通过一个几何形状接到下一个镜头（圆接圆、方接方、楔接楔），见 §2.2。不用常规叠化，除尾声一外**禁止使用软叠化**。
5. **节拍就是剪辑点。** 硬切都落在拍点上，重要事件落在实测的音频瞬态上（见 §3.3 同步点表，先实测再施工）。

---

**视觉修订（2026-11-06）**　所有生图与动画均禁止旭日、日出、红色太阳盘和日旗式放射条纹。用不汇聚的平行斜梁与错位矩形组织动势，钟面、座圈、水面、镜头等功能性圆形照常使用。

## 1. 创意总纲

### 1.1 一句话
**一部 1927 年风格的国家宣传纪录片《第三号战役纪实》：一位无名同志三次冲锋、攻克"那堵墙"，最终在"噗通"一声中赢得人生最大的胜利，全民为之庆祝。**

### 1.2 艺术参照（风格锚点，供施工模型理解，不是要求照抄）
| 参照 | 在本片中的用法 |
|---|---|
| 罗德琴科（Rodchenko）摄影 | 极端仰角/俯角、强对角线、人物照片的高反差黑白半调 |
| 利西茨基《红楔攻白军》《两个方块的故事》 | 红楔 = "它"；白墙/白圆 = 阻碍；尾声"大事小事"用红方块/黑方块对比 |
| 克鲁西斯（Klutsis）照片蒙太奇 | 主角照片被放大、复制、与人群拼贴；副歌二的"万人同心" |
| 塔特林《第三国际纪念塔》 | **胜利纪念塔**：倾斜双螺旋钢架，塔顶供着一只白瓷马桶 |
| 维尔托夫《持摄影机的人》 | "回头望一眼"= 电影眼（镜头里嵌着一只眼睛） |
| 波波娃《宽宏大量的戴绿帽者》舞台 | 厕所被搭成构成主义木架舞台：框架、轮子、坡道、梯子 |
| 斯坦伯格兄弟电影海报 | 人物与平行斜梁、急速透视、标题字体排版 |
| 纽拉特 Isotype 图标 | 尾声一"人生有多少这样的战役"的生活图标阵列 |

### 1.3 叙事结构（章节卡系统）
全片做成"纪录片的章节"，每段开头一个巨大的数字/章节卡，观众永远知道自己在第几战：

| 段落 | 章节卡 | 叙事 |
|---|---|---|
| Intro | 片头标题《人生最大的胜利》/"第三号战役纪实" | 万人集会，纪念塔剪影（塔顶被斜向挡板遮住） |
| Verse 1 | 巨大红色 **1** | 第一次冲锋：自信 → 空等 → 尴尬撤退 |
| Verse 2 | 巨大红色 **2** | 第二次出征：全军动员 → 不开腔 → 败退 → 沙发上怀疑人生 |
| Pre-Chorus | 巨大红色 **3** | 红楔顶住白墙，三进三退，与马桶两败俱伤 |
| Chorus 1 | "最后一次" | 决战 → 鬼门关 → **噗通** → 登顶、夺冠 → 揭晓胜利纪念塔 |
| Bridge | "战后检阅" | 擦汗、冲水、腿麻、电影眼回望 → 漂浮的尊严勋章 + 吉他独奏 |
| Chorus 2 | "全民的胜利" | 个人胜利变成全民狂欢：万人咬牙、全城憋红、体育场 = 马桶圈 |
| Outro 1 | 无章节卡（安静） | Isotype 人生战役、再憋一口气、两个方块 → 留白 → "好——事——！" |
| Outro 2 | "谢幕" | 全片角色和几何物在对角线上游行谢幕，定格为终极海报 |

### 1.4 镜头语言的演进弧线（保证连贯）
| 段落 | 空间 | 画面倾角（Dutch） | 镜头运动 | 节奏 |

| 旧纸黄 Aged Ochre | `#C9A45C` | 纸张污渍、旧报纸、极少量点缀 | ≤5% |
| 半调灰 Halftone Grey | `#8C857A` | 照片中间调（仅通过网点实现） | — |
| 胜利金 Victory Gold | `#D9A93A` | **只用于**尊严勋章和胜利时刻的星芒（Chorus 1 噗通之后才首次出现） | ≤8% |

- 不使用任何蓝色、绿色、渐变霓虹。水面 = 墨黑圆 + 纸白涟漪线。
- 照片素材一律处理为黑白半调（墨黑网点印在纸白上），红色只以"套印层"的方式叠在照片上。
- Blender 输出必须使用 **View Transform = Standard**（不要 AgX/Filmic），保证上述色值不被色调映射改掉。

### 2.2 几何母题系统（转场的语法）
| 母题 | 代表物 | 出现位置 |
|---|---|---|
| **圆 ●** | 马桶口、水面、钟面、扩音器口、勋章、体育场、电影眼、涟漪 | 全片主母题，所有"圆接圆"的匹配剪辑 |
| **方 ■** | 门（马列维奇黑方块）、墙、沙发、报纸、两个方块 | 受阻、封闭、日常 |
| **楔 ▲** | 红楔（它）、主角的意志、珠峰、旗帜、箭头 | 冲锋、突破、胜利 |
| **斜线 ／** | 平行斜梁、对角构图、青筋、电线、腿麻的锯齿线 | 能量、张力 |
| **螺旋 ◎** | 塔特林塔、冲水漩涡、钟表发条 | 冲水、纪念塔、升华 |

匹配剪辑规则：上一镜头最后 4–6 帧中，一个母题形状移动/放大到画面中心并充满一定面积；下一镜头第一帧同位置、同大小有同类形状。示例：钟面（圆）→ 马桶口（圆）；黑方块门 → 数字"2"的黑色方底。

### 2.3 构图法则
- 主对角线角度只用 **30°、45°、60°、90°**（及其负角），全片统一。主角冲锋方向永远是**左下 → 右上**（上升=胜利）；失败、撤退方向是**右上 → 左下**。
- 画面使用 12 列网格，大字压到画框边缘甚至出血（被裁切的巨大字 = 构成主义经典手法）。
- 每个画面最多 1 个主体 + 1 个几何主形 + 1 组文字，保持海报级的清晰。
- 人物照片常用**极端仰角**（Chorus/胜利）与**俯视**（失败、等待）。

### 2.4 字体与动态文字
| 用途 | 推荐字体（均可免费商用，施工时确认授权） |
|---|---|
| 中文主标题/歌词大字 | 庞门正道标题体、优设标题黑、站酷高端黑（三选一，全片统一一种） |
| 中文小字/字幕/图注 | 思源黑体 Heavy / Bold |
| 拉丁/数字 | Bebas Neue（窄高）、Oswald Bold |
| 俄文装饰字（极少量） | Russo One / Rubik Mono One |

动态文字的 5 种"动作"（全片只用这 5 种，形成统一语汇）：
1. **SLAM 砸入**：scale 1.8→1.0，4 帧，`Easing.out(Easing.exp)`，落地帧 1 帧纸白闪 + 3–6px 震动，带油墨飞溅边缘遮罩。
2. **THRUST 斜冲**：沿 30° 对角线从画外冲入，6 帧，无回弹，冲到位后停 0 帧硬停（机械感）。
3. **STRETCH 拉伸**：长音时字间距/scaleX 随时间增长，长音结束时 2 帧回弹。
4. **STAMP 盖章**：字带方框，旋转 -8°~+8° 随机，2 帧出现，红色印泥质感，不透明度 92%。
5. **TYPE-SET 排字**：逐字从上方落下，每字间隔 2 帧（只用在叙事慢句和尾声一）。

歌词全部上屏（作为画面设计的一部分），每句的处理方式在分镜里注明。另设一条**底部图注栏**（可选）：思源黑体 28px，墨黑底纸白字，左下角，像纪录片字幕，用来放"第一号作战记录 · 00:10:00"之类的伪纪录信息，增强纪录片感。

### 2.5 印刷质感（全片统一的后期层）
从下到上叠在每一帧上（做成全局组件 `<PrintFinish>`）：
1. **纸张纹理** T01：multiply，不透明度 100%，每 2 帧在 3 张纹理间换一张（模拟胶片逐帧不同的纸）。
2. **照片半调**：所有照片素材预处理为网点（见 §3.5）。
3. **套印错版**：所有红色层复制一层深红 `#8E1B14`，偏移 (2px, -1px)，multiply 30%；在军鼓拍上偏移跳到 (4px, -2px) 持续 2 帧。
4. **胶片颗粒/划痕** T03：screen/multiply 15%，24fps 步进更新（每 1.25 帧换一次 → 实现为每帧随机种子，但每 2 帧才更新一次）。
5. **片门晃动**：整帧 ±0.6px 随机平移，每 2 帧更新。
6. **暗角**：极轻，边缘压暗 8%。
> 尾声一（2:18–2:37）颗粒与晃动减半，营造安静。

### 2.6 运动语法
- **机械感**：主运动一律 "快进—硬停"：`Easing.out(Easing.exp)` 或 `Easing.bezier(0.16, 1, 0.3, 1)`，6–10 帧完成。禁止慢悠悠飘动（尾声一除外）。
- **棘轮旋转**：斜梁背景分步平移，齿轮、塔内几何体不连续旋转，而是**每拍跳一格**（平行斜梁每拍横移一格，用 5 帧完成，其余时间静止）——像机器一样"咔哒咔哒"。
- **节拍脉冲**：底鼓拍上主几何形 scale 1.00→1.03→1.00（6 帧）；拍手（2、4 拍）上小元素 STAMP。
- **冲击震动**：`哈！`、两次噗通的两记重击、`好事` 爆发、最后齐奏 —— 使用衰减震动：振幅 18px，频率 30Hz，衰减 12 帧。
- **骤停（Stop-time）**：两次"噗通一声"后，画面所有运动**冻结**（包括纸纹、颗粒、晃动全部冻结），直到重击才解冻。这是全片最重要的同步。

## 3. 技术规格

### 3.1 合成参数
- Composition id：`LifeVictoryMV`
- 分辨率 **1920×1080**，**30 fps**，时长 **5146 帧**（171.53 s × 30，向上取整）
- 音频：`<Audio src={staticFile('audio/人生最大的胜利.mp3')} />`
- 安全框：主要文字在 1920×1080 中央 90% 内；如需竖屏版，主体与大字保持在中央 608px 宽的 9:16 安全带内可被二次裁切（可选，不强制）。

### 3.2 节拍网格
- 1 拍 = 60/123 = **0.487805 s = 14.634 帧**
- 1 小节 = **58.537 帧**，8 小节 = 468.3 帧 ≈ 15.61 s（与各段落长度吻合）
- 工具函数：
```ts
export const FPS = 30;
export const BEAT = (60 / 123) * FPS;   // 14.634
export const BAR = BEAT * 4;            // 58.537
export const OFFSET = 0;                // 第一个强拍的帧号，需实测后填写
export const beatFrame = (n: number) => Math.round(OFFSET + n * BEAT);
export const barFrame  = (n: number) => Math.round(OFFSET + n * BAR);
```
- **施工第一步必须实测**：用 librosa（`librosa.beat.beat_track` + `librosa.onset.onset_detect`）或 aubio 跑一遍音频，得到真实 OFFSET 和下表各事件的精确秒数，写入 `src/sync.ts`。下表是根据音乐分析文档给出的**估计值**，误差可能有 ±0.3 s。

### 3.4 图层结构（每帧从下到上）
```
L0  纸张底色 #EDE3CC
L1  背景几何（平行斜梁、大圆、大方块、网格）— Remotion SVG
L2  Blender 渲染层（透明 PNG 序列）
L3  照片蒙太奇层（AI 生图 + 抠图 + 半调处理）
L4  前景几何（红楔、箭头、线条）
L5  文字层（歌词、章节数字、图注）
L6  印刷质感 <PrintFinish>
L7  冲击震动（作用于 L1–L5 整体的 transform）
```

### 3.5 照片素材处理流程
1. AI 生图（黑白、纯灰背景）→ 抠图得到 RGBA PNG。
2. **离线预处理（推荐）**：Python（Pillow + numpy）把每张抠图转为"墨黑网点 + 纸白底色"的双色半调 PNG，保留 alpha。网点：圆点、45° 网角、网线数约 55 lpi（1080p 下网点间距约 6px；人物大特写可放大到 9px 以显粗犷）。输出 `xxx_ht.png`。
3. 红色套印：需要"变红"的照片（如"脸憋得通红"）在 Remotion 中叠一层红色 `#D52B1E`，用 alpha 遮罩限定在人物上，`mix-blend-mode: multiply`，不透明度可动画。
4. 回退方案：不做预处理时，用 CSS `filter: grayscale(1) contrast(1.4) brightness(1.05)` + 一层网点 SVG pattern multiply，被照片 alpha 遮罩。

### 3.6 Blender → Remotion 接口
- 输出 PNG 序列 RGBA（Film → Transparent 勾选），16 bit 不需要，8 bit 即可，颜色管理 Standard。
- 默认渲染 **30 fps**；带 `@60` 标注的序列渲染 60 fps（用于骤停/慢动作的时间重映射）。
- 文件路径：`public/blender/<场景ID>_<机位>/<图层>/0001.png`
- Remotion 中用自定义组件 `<BlenderSeq dir="..." start={...} rate={1} freezeAt={...} />` 按帧号取图（`staticFile` + `<Img>`），支持时间重映射和冻结。若序列过多影响渲染速度，可用 ffmpeg 转成 ProRes 4444 或 VP9 WebM（带 alpha）后用 `<OffthreadVideo transparent>`。
- 需要分层的场景（如噗通水花）按 View Layer 分层输出，Remotion 中分别控制时间。

## 5. Blender 场景施工单

### 5.0 通用设置（所有场景）
- 渲染引擎：默认 **EEVEE**（扁平构成主义质感，速度快）；标注 `[Cycles]` 的用 Cycles（白瓷、金属勋章、水面需要真实反射）。
- 分辨率 1920×1080，帧率 30（标 @60 的为 60）。
- Film → Transparent；Color Management → View Transform **Standard**，Look None，Exposure 0，Gamma 1。
- **构成主义着色器（Toon 扁平着色）**，所有非白瓷物体使用：
  ```
  Principled/Diffuse BSDF → Shader to RGB → Color Ramp (Constant 插值，3 档)
    档位：暗部 / 中间 / 亮部，例如红色物体：#8E1B14 / #D52B1E / #E8584A(极少)
  → Emission (Strength 1) → Material Output
  ```
  EEVEE 中 Shader to RGB 可用。需要纯平面色的物体直接 Emission 纯色。
- 可选描边：Freestyle，线宽 2.0px，颜色 #141210，只勾 Silhouette + Crease。或用 Solidify 反向法线描边。保持全片统一（建议：塔、门、拱门、领奖台开描边；水花、漩涡不开）。
- 光照：一盏 Sun 灯，角度 45° 从左上方打下（与 2D 层统一的光向：左上），强度以 Toon 色阶分界清晰为准。世界背景透明。
- 所有颜色只能来自 §2.1 色板。
- 相机：构成主义要求强透视 —— 仰拍用 14–24mm，正面/平面感镜头用正交相机或 135mm 以上长焦。
- 每个场景交付：`.blend` 文件 + PNG 序列 + 一张静帧 `preview.png`。

### BL-01 胜利纪念塔（S02 / S24 / S34 / S40）
- **结构**（致敬塔特林第三国际纪念塔）：
  - 塔轴整体向右倾斜 **23°**。
  - 两条相互缠绕的锥形螺旋钢架：底半径 6m → 顶半径 1.2m，高 30m，4 圈。用 Curve Spiral（或 Geometry Nodes：Curve Spiral 节点）生成，Bevel 方形截面 0.3m；第二条螺旋相位差 180°。
  - 两条主斜梁（直线钢梁）从塔基贯穿到塔顶，沿倾斜轴，截面 0.5m。
  - 螺旋之间每隔 1m 用横撑和 X 形斜撑连接（几何节点在螺旋曲线点上实例化杆件）。
  - 塔内部悬挂 4 个几何体（自下而上）：纸白**立方体** 4m、红色**四棱锥** 3m、黑色**圆柱** 2.5m、纸白**半球** 1.5m。每个以不同速度绕塔轴自转，**棘轮式**：每小节（58.537 帧）旋转一次 90°，用 Bezier 关键帧 0→90° 在 10 帧内完成，然后静止到下一小节（立方体每小节、锥每 2 拍、柱每拍、半球每 2 小节）。
  - **塔顶平台**：圆形红色平台，中央一个纸白基座，基座上一只**白瓷马桶**（老式，带水箱）。`[Cycles]` 白瓷材质：Principled，Base #F3EFE6，Roughness 0.08，Coat 0.5；马桶水面：小圆平面，黑色玻璃感 #141210，Roughness 0.02。马桶建模：碗体用 Screw/Lathe 一条截面曲线旋转，椭圆缩放 X 0.8；座圈为椭圆 Torus；水箱为倒角长方体；也可用可商用免费模型。
  - 塔基：黑色大圆台 + 3 级台阶。
  - 钢架材质：Toon 红；描边开。
- **机位**：
  - **A（S02，120 帧，30fps）**：18mm，相机在塔基外 8m、离地 1m，仰角 60°。0→120 帧相机沿塔轴方向上升 12m 并绕塔转 15°（Bezier，easeOut）。**构图要保证塔顶始终在画框外或在画面上沿 1/5 区域**（Remotion 会在那里叠一块斜向矩形挡板）。
  - **B（S24，240 帧）**：连续大拉远。起幅：相机在马桶水面上方 0.15m 正对水面（85mm），画面只有黑色水面（Remotion 会在水面叠金牌倒影的反光）。0–60 帧：后拉到看见整只马桶（50mm）；60–150 帧：继续后拉并上升，看到塔顶平台与上部钢架（35mm，焦距动画）；150–240 帧：拉到塔全景，塔占画面高度 75%，相机仰角 15°，塔位于画面中心偏左（右侧给文字留空）。全程 Bezier easeInOut，焦距同步变化以避免透视突变；**全片最重要的 3D 镜头，务必流畅无抖**。`[Cycles]`
  - **C（S34，240 帧）**：24mm 低角度环绕，绕塔轴转 120°，相机高度 3m → 8m，塔占画面 90% 高度。塔顶马桶口发出 4 道光——在 Blender 中放一个小 Emission 圆盘（金 #D9A93A）+ Bloom，或交给 Remotion 加光芒（推荐 Remotion，可控）。
  - **D（S40 谢幕用，静帧 + 30 帧小转动）**：正交相机侧面，塔完整，用于在传送带上"游行"。
- **输出分层**：`tower`（塔全部）、`toilet`（单独马桶层，便于 Remotion 加光效）。

### BL-05 红楔与墙（S13 / S14 / S36）
- **墙**：纸白砖墙，6m×6m×1m，用阵列砖块（0.5×0.25×1m，砖缝 0.02m 黑色）。Toon 纸白，暗部 #C9C0AA。
- **红楔**：细长的三棱锥/楔形（长 4m、底宽 1.2m、高 0.8m），Toon 红，尖端锐利，描边开。
- **裂纹**：在墙面红楔接触点周围做裂纹（Cell Fracture 预裂 + 只位移几毫米，或用黑色细裂纹贴图/形状键逐步显现）。
- **机位 A（S13+S14，222 帧）**：侧前方 45°，35mm，红楔从左侧刺入。0–20 帧红楔冲到墙面（硬停，带 1 帧撞击回弹），之后每拍红楔向墙推进 0.02m（顶的动作），裂纹逐渐扩大（162 帧时裂纹延伸 1m，但不破）。另渲染 S14 的特写机位 A2：85mm 对准尖端与裂缝，30 帧。
- **机位 B（S36，120 帧）**：正面平视，正交或 135mm，墙缩小到占画面 30% 高度，安静、简洁；最后 30 帧裂缝出现一条细竖缝（裂缝里的金光由 Remotion 加）。

### BL-06 鬼门关（S20 / S30）
- 一条由 8 道**黑色构成主义拱门**组成的隧道：每道门为方形框（外 8m×10m，梁截面 1m），交替加入斜撑和半圆拱，每道门旋转偏移 7.5°（形成螺旋隧道感）。门与门间距 6m。
- 两侧：巨型活塞（红色圆柱缸体 + 纸白活塞杆，循环伸缩，每拍一次）和 3 个巨大压力表（纸白圆盘 + 黑刻度，指针红色指向红区）。
- 最外第一道门的顶梁正面留出平整面板（供 Remotion 贴"鬼门关"三字，或直接在 Blender 中建纸白 Text 物体——中文需加载中文字体文件，推荐 Remotion 贴图）。
- **机位 A（S20，144 帧）**：相机从隧道入口外 20m 出发，沿隧道轴心加速前进（Bezier easeIn 前段，匀速穿越），**每拍穿过一道门**（门间距 6m，速度 6m/14.634 帧），相机绕前进轴滚转 30°（整个过程）。镜头前方 3m 处有一个红楔与相机同步前进（红楔挂在相机父级下，轻微上下浮动）。最后 15 帧：穿出隧道，前方下方出现一个墨黑大圆盘（水面），红楔开始下坠（交接 BL-07）。
- **机位 B（S30，120 帧）**：同一隧道，相机路径偏低、偏一侧。用 Geometry Nodes 在相机周围实例化 **300 个红楔**（随机大小 0.3–1.5、随机位置在隧道截面内、全部朝向前进方向、速度略快于相机，形成"超越"的感觉）。

### BL-07 噗通（S21 / S31）★全片最关键 3D 资产 [@60]
- 不做流体模拟（不可控、风格不符），做**风格化几何水花**：
  - **水面**：墨黑大圆盘（S21 侧视时为椭圆透视），材质 Emission #141210。
  - **红楔**：同 BL-05 的红楔（缩小到 1m 长），尖端朝下坠落。
  - **皇冠水冠（crown）**：24 片纸白锐利的细长楔形片，沿圆周径向排列、向外倾斜 20°；动画：入水帧 F0 时 scale 0，F0+3 帧（@60）迅速长到最大高度 1.5m（easeOut），F0+20 回落缩短到 0（easeIn）。每片长度随机 ±20%。
  - **飞溅水滴**：40 个纸白小球/小菱形，从入水点沿抛物线飞出（用 Geometry Nodes 或粒子：初速度向上 + 随机径向，重力），在 30 帧（@60）内落回。
  - **涟漪**：6 个纸白细环（Torus 或平面环，线宽 0.03m），从中心依次扩散：每个环在 F0+5×i 帧出现，60 帧内半径从 0.2 扩大到 8m，线宽变细到 0.01m，在 Remotion 中再做透明度。
- **机位 A（S21，侧视）**：相机与水面夹角 20°，50mm，水面椭圆占画面宽 60%。红楔从画面上方入画，下落 40 帧（@60）到达水面上方 0.05m（**这一帧标记为 FREEZE_FRAME**，Remotion 冻结用），之后入水。
- **机位 B（S31，正俯视）**：正交相机向下，水面正圆；红楔从镜头方向下坠（scale 由大变小表现透视，用透视相机 85mm 更自然——两种都渲染，施工选效果好的）。
- **分层输出（View Layers）**：`water`、`wedge`、`crown`、`droplets`、`ripples`。Remotion 中：冻结时只显示 water + wedge 冻结帧；hit1a 时触发 crown + droplets；hit1b 时触发 ripples 快速扩散段。
- 总长渲染 180 帧 @60（3 秒）。

### BL-08 珠峰与领奖台（S23 / S33）
- **珠峰**：一座低多边形红色山体（Icosphere 拉伸/手工三角面，主峰明显的锐利三角形剪影，2–3 个次峰），面片 Toon 红（亮面 #D52B1E、暗面 #8E1B14 两档硬分界），峰顶 1/5 为纸白雪线（锯齿状交界）。
- **领奖台**：三个长方体，1 号（红，高 1.2m）居中，2 号（黑，高 0.8m）左，3 号（黑，高 0.5m）右；正面留平面给 Remotion 贴"1/2/3"数字（或 Blender 内建纸白数字形状，用 Bebas 字形的 Text 物体）。
- **机位 A（S23a，60 帧）**：仰拍 24mm，峰顶在画面上 1/3，相机缓慢上推 5°。峰顶留出主角照片合成位置（峰尖右侧一块平台）。
- **机位 B（S23b，60 帧）**：正面平视 50mm，领奖台居中，1 号台顶面高度在画面下 1/3，背后透明。
- **机位 C（S33，120 帧）**：山顶上放领奖台，相机从山脚仰拍快速升到峰顶平视（前 60 帧，easeInOut），后 60 帧静止在峰顶领奖台正面中景。

### BL-09 冲水漩涡（S25）
- 一个俯视的螺旋漩涡：用 Archimedean 螺旋曲线（或平面上用 Geometry Nodes 生成）铺满一个圆面，交替红/纸白条带，条带宽度由外向内变窄；中心是墨黑小圆（下水口）。
- 加 Simple Deform（Twist）+ 向中心的下陷位移，让漩涡呈漏斗形。
- 动画：整体绕中心旋转，每拍 90°（这里不用棘轮，连续加速旋转，表现水流），90 帧内角速度从 1x 到 3x，最后 15 帧整体缩小到中心一点（交接下一镜）。
- **机位 A**：正俯视，50mm，漩涡充满画面。

### BL-10 漂浮尊严勋章（S27）[Cycles]
- **水面**：墨黑大平面，材质：Base #141210，Roughness 0.05，带轻微 Wave 纹理法线（低频、慢速起伏）。反射环境用一张纯纸白/黑分区的简单 HDRI 或两块 Emission 面板（左右上方各一，模拟体育场灯），让水面出现两条长条反光。
- **勋章**：五角红星（挤出 0.08m，倒角，表面红色珐琅：Base #D52B1E，Roughness 0.2，Coat 1.0）+ 金色外圈（圆形或十二角星芒底座，Metallic 1，Base #D9A93A，Roughness 0.25）+ 下方红色绶带（布料或简单弯折平面，Toon 红）。勋章直径 0.3m，平躺漂在水面，露出水面一半厚度。
- **涟漪**：勋章周围 3 个纸白细环，缓慢扩散循环。
- 动画：勋章随水面轻微起伏（±0.01m，周期 = 2 小节）和缓慢自转（210 帧内 15°）。
- **机位 A（210 帧）**：低角度贴水面（离水面 0.15m）、50mm，绕勋章环绕 60°，勋章在画面中心偏下。焦外虚化 f/2.8，勋章锐利。
- 输出：`water`、`medal`、`ripples` 三层。

### BL-11 体育场俯视 = 马桶圈（S31 / S32）
- **形状设计是本梗的关键**：体育场整体轮廓必须与 O-02（马桶正俯视照片）的轮廓一致——**椭圆形环 + 一端较宽**（像马桶圈的前后比例），马桶水箱所在的一端做成一座长方形的**主看台/检阅台**（水箱 = 主看台）。施工时先拿到 O-02 抠图，提取轮廓，在 Blender 中以它为参考画体育场轮廓曲线。
  - 看台：沿轮廓曲线向外 10 圈台阶（Array + Curve 修改器），材质 Toon 纸白/灰；看台上用 Geometry Nodes 在每级台阶实例化密集的小圆点（人群），黑色，大小随机 ±30%（俯视下就是半调网点的感觉——这是体育场"人群=网点"的又一个巧思）。
  - 中央球场 = 墨黑椭圆水面（与 BL-07_B 的水面严格对位，位置、大小一致，便于 Remotion 叠 BL-07_B 的水花层）。
  - 外圈：红色环形屋檐，描边开。
- 动画：人群点在 hit2b 时"跳起"——在 Geometry Nodes 中用一个控制值（0→1→0）驱动所有点 scale 1→1.3→1（6 帧），帧号与 hit2b 对齐（或在 Remotion 中用整体缩放近似）。bandBack2 之后相机开始旋转上升（90 帧内旋转 45°、上升，体育场缩小到画面 40%）。
- **机位 A**：正交俯视（与 O-02 匹配剪辑），之后切换为透视上升（可以渲染两段）。

### BL-12 构成主义城市（S24 远景 / S29 / S34）
- 一组构成主义建筑剪影：工厂（锯齿屋顶）、4–6 根烟囱、2 座无线电塔（舒霍夫双曲面塔造型：Hyperboloid 格构，致敬莫斯科舒霍夫塔）、几座阶梯状楼（盒子叠加）、高压线塔与电线（Curve，线宽 0.05m）。
- 所有建筑仅用纸白、黑两色 Toon（S29 需渲染一版**全红**版本：把纸白替换为 #D52B1E，暗面 #8E1B14）。
- **电线**：单独层 `wires`，供 Remotion 做红色脉冲流动（或在 Blender 中用 Emission 贴图动画做流动光点）。
- **机位 A（S29，120 帧）**：仰拍 20mm，城市天际线位于画面下 2/3，相机缓慢前推。分层：`city_cream`、`city_red`、`wires`。
- **机位 B（S24/S34 远景）**：长焦 135mm 远景天际线，作为塔背后的远景层（静帧即可，Remotion 做视差）。

## 7. 施工顺序与质检

### 7.1 建议施工顺序
1. **音频实测**：跑节拍与瞬态检测，填写 `sync.ts`（OFFSET 和 ★ 事件）。
2. **风格定调**：先生成 K-03 风格参考帧 + H-00 角色设定表，确认风格与角色后再批量生成。
3. 批量生成 H/C/CR/HD/O/K/T 素材 → 抠图 → 半调预处理。
4. Blender：先做 BL-07（噗通）和 BL-01（纪念塔，尤其机位 B）——这是全片最关键的两个镜头；其余按镜头顺序。
5. Remotion：先搭全局组件（PaperBG、PrintFinish、KineticText、ParallelSlats、BlenderSeq、Shake），再按段落搭 Sequence。**先用灰块占位把 42 个镜头的时间轴全部搭完并对音频预览**，确认节奏后再替换真实素材。
6. 精修同步点 → 全片渲染 → 质检。

### 7.2 质检清单
- [ ] ★ 同步点全部对齐到实测瞬态帧（尤其两次骤停冻结、两次重击、`哈！`、`好事` 爆发、Final Hit）。
- [ ] 骤停期间画面**完全**静止（包括颗粒、纸纹、晃动）。
- [ ] 全片无排泄物具象、无裸露；"它"始终是红楔，漂浮物是勋章。
- [ ] 颜色只来自色板；Blender 输出用了 Standard 色彩管理；金色在 S21 之前没有出现过。
- [ ] 每个镜头的出画与下一镜头入画通过几何母题衔接，没有生硬跳切、没有意外的软叠化（尾声一除外）。
- [ ] 所有歌词均以设计化方式上屏，且可读（每句至少停留 1 拍完整可读）。
- [ ] 主角在所有 H 系列素材中长相一致（脸型、帽子、衣服）。
- [ ] S02 塔顶被遮住，S24 才揭晓马桶；S31 体育场轮廓与马桶俯视轮廓一致。
- [ ] 主角冲锋方向左下→右上，失败方向右上→左下，全片无矛盾。
- [ ] 最后一帧与音频同时结束（5146 帧）。
